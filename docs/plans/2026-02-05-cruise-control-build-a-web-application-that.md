# SQLite Database Editor Web Application - Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a web application that allows authenticated users to manage an SQLite database (create/drop tables, add/remove columns, browse/edit data) using a Rust backend with htmx frontend.

**Architecture:** Rust Axum web server serves htmx-powered HTML. Authentication validates externally-issued RS256 JWT tokens against a local CA. SQLite database stores user-managed data. The app exposes a `.well-known/jwks.json` endpoint for public key discovery. E2E tests use Playwright with short-lived self-signed JWTs.

**Tech Stack:**
- Backend: Rust (Axum 0.8, rusqlite, jsonwebtoken, tower-http)
- Frontend: htmx 2.x, minimal CSS
- Auth: RS256 JWT with local CA (openssl-generated keys)
- Testing: Playwright (TypeScript)
- CI: GitHub Actions (super-linter v8, dependency-review-action v4)

---

## Overview

The application is a lightweight SQLite database administration tool. Users authenticate via JWT bearer tokens issued by an external process (in testing, generated by a helper script). The Rust backend validates tokens using a local RSA key pair exposed via a JWKS endpoint. The htmx frontend dynamically updates the UI without full page reloads, allowing users to manage tables and columns.

Key architectural decisions:
1. **External JWT validation only** - The app does not issue tokens. Tokens are created externally (test helper or external IdP). The app only validates them via the `.well-known/jwks.json` public key.
2. **rusqlite for SQLite** - Direct SQLite bindings without ORM overhead. Suitable for dynamic schema management.
3. **htmx for interactivity** - Server-rendered HTML fragments returned by the API, swapped in by htmx. No JavaScript framework needed.
4. **Axum middleware for auth** - Tower-based middleware extracts and validates JWT from Authorization header on protected routes.

## Risk Areas

1. **Dynamic schema management** - ALTER TABLE in SQLite has limitations (e.g., cannot drop columns in older SQLite versions). Must use SQLite 3.35.0+ for `ALTER TABLE DROP COLUMN`, or implement workaround via table recreation.
2. **SQL injection** - Dynamic table/column name operations cannot use parameterized queries for identifiers. Must use allowlists and strict validation.
3. **Concurrent access** - SQLite has limited concurrent write support. rusqlite's default connection pooling handles this, but heavy concurrent writes could be an issue.
4. **JWT key rotation** - Current design uses a single key pair. No rotation mechanism, acceptable for this scope.
5. **htmx CSRF** - htmx requests need CSRF protection. Using JWT in Authorization header (not cookies) avoids this concern.
6. **Playwright test flakiness** - E2E tests need proper waits for htmx swaps. Use Playwright's `waitForSelector` and `waitForResponse` patterns.

```rust
use axum::{
    extract::Request,
    http::{header, StatusCode},
    middleware::Next,
    response::Response,
};

pub async fn auth_middleware(
    State(state): State<Arc<AppState>>,
    mut req: Request,
    next: Next,
) -> Result<Response, StatusCode> {
    let auth_header = req
        .headers()
        .get(header::AUTHORIZATION)
        .and_then(|v| v.to_str().ok())
        .ok_or(StatusCode::UNAUTHORIZED)?;

    let token = auth_header
        .strip_prefix("Bearer ")
        .ok_or(StatusCode::UNAUTHORIZED)?;

    let claims = validate_jwt(token, &state.public_key_pem)
        .map_err(|_| StatusCode::UNAUTHORIZED)?;

    req.extensions_mut().insert(claims);
    Ok(next.run(req).await)
}
```

```rust
use rusqlite::{Connection, Result, params};

/// Validate a table/column name to prevent SQL injection.
/// Only allows alphanumeric characters and underscores, must start with a letter.
fn validate_identifier(name: &str) -> Result<&str, String> {
    if name.is_empty() {
        return Err("Identifier cannot be empty".to_string());
    }
    if !name.chars().next().unwrap().is_ascii_alphabetic() {
        return Err("Identifier must start with a letter".to_string());
    }
    if !name.chars().all(|c| c.is_ascii_alphanumeric() || c == '_') {
        return Err("Identifier can only contain letters, digits, and underscores".to_string());
    }
    if name.len() > 64 {
        return Err("Identifier too long (max 64 chars)".to_string());
    }
    Ok(name)
}

pub fn list_user_tables(conn: &Connection) -> Result<Vec<String>> {
    let mut stmt = conn.prepare(
        "SELECT name FROM sqlite_master WHERE type='table' AND name NOT LIKE 'sqlite_%'"
    )?;
    let tables = stmt.query_map([], |row| row.get(0))?.collect::<Result<Vec<String>>>()?;
    Ok(tables)
}

pub fn create_user_table(conn: &Connection, name: &str, columns: &[&str]) -> Result<(), String> {
    let name = validate_identifier(name)?;
    // Validate each column definition
    let validated_cols: Vec<String> = columns
        .iter()
        .map(|col| {
            let parts: Vec<&str> = col.split_whitespace().collect();
            if parts.is_empty() {
                return Err("Empty column definition".to_string());
            }
            validate_identifier(parts[0])?;
            Ok(col.to_string())
        })
        .collect::<Result<Vec<_>, _>>()?;

    let cols = validated_cols.join(", ");
    let sql = format!("CREATE TABLE \"{}\" ({})", name, cols);
    conn.execute(&sql, []).map_err(|e| e.to_string())?;
    Ok(())
}

pub fn drop_user_table(conn: &Connection, name: &str) -> Result<(), String> {
    let name = validate_identifier(name)?;
    let sql = format!("DROP TABLE IF EXISTS \"{}\"", name);
    conn.execute(&sql, []).map_err(|e| e.to_string())?;
    Ok(())
}

pub fn get_table_columns(conn: &Connection, table: &str) -> Result<Vec<(String, String)>, String> {
    let table = validate_identifier(table)?;
    let sql = format!("PRAGMA table_info(\"{}\")", table);
    let mut stmt = conn.prepare(&sql).map_err(|e| e.to_string())?;
    let columns = stmt
        .query_map([], |row| {
            Ok((row.get::<_, String>(1)?, row.get::<_, String>(2)?))
        })
        .map_err(|e| e.to_string())?
        .collect::<rusqlite::Result<Vec<_>>>()
        .map_err(|e| e.to_string())?;
    Ok(columns)
}

pub fn add_column(conn: &Connection, table: &str, col_name: &str, col_type: &str) -> Result<(), String> {
    let table = validate_identifier(table)?;
    let col_name = validate_identifier(col_name)?;
    // col_type should be a known SQLite type
    let valid_types = ["TEXT", "INTEGER", "REAL", "BLOB", "NUMERIC"];
    let col_type_upper = col_type.to_uppercase();
    if !valid_types.contains(&col_type_upper.as_str()) {
        return Err(format!("Invalid column type: {}", col_type));
    }
    let sql = format!("ALTER TABLE \"{}\" ADD COLUMN \"{}\" {}", table, col_name, col_type_upper);
    conn.execute(&sql, []).map_err(|e| e.to_string())?;
    Ok(())
}

pub fn remove_column(conn: &Connection, table: &str, col_name: &str) -> Result<(), String> {
    let table = validate_identifier(table)?;
    let col_name = validate_identifier(col_name)?;
    // SQLite 3.35.0+ supports ALTER TABLE DROP COLUMN
    let sql = format!("ALTER TABLE \"{}\" DROP COLUMN \"{}\"", table, col_name);
    conn.execute(&sql, []).map_err(|e| e.to_string())?;
    Ok(())
}
```

```rust
fn render_table_list(tables: &[String]) -> String {
    // Returns HTML fragment for htmx to swap
    let mut html = String::from("<ul id=\"table-list\">");
    for table in tables {
        html.push_str(&format!(
            r#"<li>
                <a hx-get="/api/tables/{name}" hx-target="#detail-panel">{name}</a>
                <button hx-delete="/api/tables/{name}" hx-target="#table-list" hx-swap="outerHTML"
                        hx-confirm="Drop table '{name}'?">Drop</button>
            </li>"#,
            name = table
        ));
    }
    html.push_str("</ul>");
    html
}

                <td>{col_type}</td>
```

```rust
mod auth;
mod db;
mod handlers;

use axum::{middleware, routing::{get, post, delete}, Router};
use rusqlite::Connection;
use std::sync::{Arc, Mutex};
use tower_http::services::ServeDir;

pub struct AppState {
    pub jwks_json: String,
    pub public_key_pem: Vec<u8>,
    pub db: Mutex<Connection>,
}

#[tokio::main]
async fn main() {
    tracing_subscriber::fmt::init();

    // Load keys
    let public_pem = std::fs::read_to_string("certs/public.pem")
        .expect("Missing certs/public.pem - run scripts/generate-keys.sh first");
    let jwks_json = auth::build_jwks(&public_pem).expect("Failed to build JWKS");
    let public_key_pem = public_pem.into_bytes();

    // Open SQLite database
    let conn = Connection::open("data.db").expect("Failed to open SQLite database");

    let state = Arc::new(AppState {
        jwks_json,
        public_key_pem,
        db: Mutex::new(conn),
    });

    let protected = Router::new()
        .route("/api/tables", get(handlers::list_tables).post(handlers::create_table))
        .route("/api/tables/{name}", get(handlers::get_table_detail).delete(handlers::drop_table))
        .route("/api/tables/{name}/columns", post(handlers::add_column))
        .route("/api/tables/{table}/columns/{column}", delete(handlers::remove_column))
        .route_layer(middleware::from_fn_with_state(state.clone(), auth::auth_middleware));

    let public = Router::new()
        .route("/health", get(|| async { "ok" }))
        .route("/.well-known/jwks.json", get(|State(state): axum::extract::State<Arc<AppState>>| async move { state.jwks_json.clone() }));

    let app = Router::new()
        .merge(public)
        .merge(protected)
        .nest_service("/static", ServeDir::new("static"))
        .fallback_service(ServeDir::new("static").append_index_html_on_directories(true))
        .with_state(state);

    let listener = tokio::net::TcpListener::bind("0.0.0.0:3000").await.unwrap();
    tracing::info!("listening on {}", listener.local_addr().unwrap());
    axum::serve(listener, app).await.unwrap();
}
```

```typescript
// tests/e2e/helpers/jwt.ts
import { execSync } from 'child_process';
import * as fs from 'fs';
import * as path from 'path';
import * as crypto from 'crypto';

export function generateTestJwt(expiresInSeconds: number = 300): string {
  const privateKeyPath = path.resolve(__dirname, '../../../certs/private.pem');
  const privateKey = fs.readFileSync(privateKeyPath, 'utf8');

  const header = {
    alg: 'RS256',
    typ: 'JWT',
    kid: 'default',
  };

  const now = Math.floor(Date.now() / 1000);
  const payload = {
    sub: 'test-user',
    iat: now,
    exp: now + expiresInSeconds,
  };

  const encodedHeader = Buffer.from(JSON.stringify(header)).toString('base64url');
  const encodedPayload = Buffer.from(JSON.stringify(payload)).toString('base64url');
  const signingInput = `${encodedHeader}.${encodedPayload}`;

  const sign = crypto.createSign('RSA-SHA256');
  sign.update(signingInput);
  const signature = sign.sign(privateKey, 'base64url');

  return `${signingInput}.${signature}`;
}
```
